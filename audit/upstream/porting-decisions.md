# SillyTavern 1.18.0 → 1.19.0 移植决策表 (porting-decisions)

| 变更模块 / 上游文件 | 变更摘要 | 影响范围 | 关联插件 | 决策类别 | rikkaST 落点与实现方式 |
|---|---|---|---|---|---|
| `public/scripts/message-formatter.js` & `public/script.js` | 新增 `MessageFormatter` 三阶段管线 (`BEFORE_REGEX`, `AFTER_REGEX`, `AFTER_MARKDOWN`) 及优先级排序 | 消息展示、HTML 块提取、正则前后钩子 | `ST-iPhonie`, `LittleWhiteBox`, `JS-Slash-Runner` | **直接移植 + Kotlin/Compose 桥接** | 新增 `st-compat/message-formatter.js`，接入 `runtime.js` 的 `stMessageFormatting` 与 `stCtx.messageFormatter`，并通过 `TavernRuntimeManager.formatMessageWithHooks` 接入 `StRegexedText.kt` / `ChatMessage.kt` |
| `public/scripts/extensions.js` & `public/script.js` | 扩展 `manifest.json` 的 `hooks` (`enable`, `disable`, `delete`, `activate`) 与 `generate_interceptor` 生命周期 | 第三方扩展加载、启停、卸载、生成拦截 | `ST-iPhonie`, 全部扩展 | **直接移植 + Android 等价实现** | 扩展 `TavernExtensions.kt` 解析 `generate_interceptor`/`hooks`/`optional`/`minimum_client_version`；在 `runtime.js` 中管理扩展模块导出生命周期并在 `__rikkaRunGenerationHooks` 中按 `loading_order` 执行 `generate_interceptor` |
| `public/scripts/macros/definitions/variable-macros.js` | 新增 `setvarkey`/`getvarkey`/`setglobalvarkey`/`getglobalvarkey`（含 `*varindex` 别名） | 宏求值、结构化 JSON 变量读写 | `ST-Prompt-Template`, `JS-Slash-Runner`, `LittleWhiteBox` | **直接移植 + Kotlin 宏引擎实现** | 在 `MacroDefinitions.kt` 与 `st-compat/macros/macro-system.js` 同步实现 JSON 深路径读写宏 |
| `public/scripts/macros/definitions/comment-closing-macros.js` & `MacroCstWalker.js` & `MacroLexer.js` | 新增 `{{///}}` 闭合注释宏与 `MacroLexer` 竖线参数修复 | 宏词法/语法树求值 | `ST-Prompt-Template`, 预设模板 | **直接移植** | 在 `MacroEngine.kt` / `MacroDefinitions.kt` 支持 `{{///}}` 闭合注释及引号内竖线保护 |
| `vendor/st/eventemitter.js` & `runtime.js` | `eventSource.emitAndWait` 异步等待与 `makeLast`/`makeFirst` 顺序保证 | 生成钩子 `CHAT_COMPLETION_SETTINGS_READY` / `CHAT_COMPLETION_PROMPT_READY` | `ST-Prompt-Template`, `st-memory-enhancement`, `JS-Slash-Runner`, `LittleWhiteBox` | **直接移植修复** | 修复 `vendor/st/eventemitter.js` 中 `emitAndWait` 未 `await` 异步监听器的问题；在 `runtime.js` `__rikkaRunGenerationHooks` 中全面 `await` |
| `GenerationLoop.kt` & `TavernScripts.kt` | 允许生成钩子增删改消息数组（取消 `parsed.size == internalMessages.size` 死锁限制） | 真实模型请求构建 | `ST-Prompt-Template`, `st-memory-enhancement`, `ST-iPhonie` | **Android 核心修复** | 修改 `GenerationLoop.kt` 与 `TavernScripts.kt`，支持变长消息数组写回、角色校验、体积上限保护及 `aborted` 中断信号 |
| `public/scripts/openai.js` & `runtime.js` | `/api/backends/chat-completions/generate` 支持 `stream: false` JSON 与 `stream: true` SSE；补齐 `openai.js` 1.19.0 导出函数 | 扩展后台 LLM 请求与流式读取 | `JS-Slash-Runner`, `LittleWhiteBox` | **直接移植 + Fetch 补丁修复** | 修复 `runtime.js` `handleGenerate` 根据 `body.stream` 返回 JSON 或 SSE；升级 `st-compat/openai.js` 完整支持 `sendOpenAIRequest`、`createGenerationParameters`、`getStreamingReply` 等 |
| `/user/files/*` & `/api/files/{upload,delete}` | 用户文件上传、读取、删除 API | 扩展大文件/音频/状态持久化 | `LittleWhiteBox` (`StorageFile`), `ST-iPhonie` (`tavernFiles`) | **Android 等价实现** | 在 `TavernRuntimeManager.kt` (`RikkaBridge`) 与 `runtime.js` fetch 补丁中实现基于 `filesDir/tavern-user-files/` 的安全文件读写删 API |
| `server-plugin/littlewhitebox-server` & Node.js 宿主 | 共享 Linux Workspace Node.js 运行时与服务端插件挂载 | 服务端生图任务、Draw Runs、Exa 搜索、Loopback Host Client | `LittleWhiteBox` | **Android PRoot + 共享 Node.js 守护进程实现** | 新增 `NodeRuntimeManager.kt`、`TavernNodeServiceManager.kt` 与 `node-host/server-bootstrap.cjs`，在 loopback `127.0.0.1` 托管共享 Node.js 服务与 `littlewhitebox-server` |
| `public/script.js` (`CLIENT_VERSION = '1.19.0'`) | 统一客户端与兼容层版本号为 `'1.19.0'` | 扩展最低版本门禁检查 (`minimum_client_version`, JSR semver) | `ST-iPhonie`, `JS-Slash-Runner` | **直接移植** | 统一 `TavernRuntimeManager.kt`、`runtime.js`、`st-compat/script.js` 版本号为 `'1.19.0'` |
