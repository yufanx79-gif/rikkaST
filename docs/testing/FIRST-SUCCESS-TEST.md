# 新用户 3 分钟首启成功测试脚本（First-Success Test）

本测试脚本用于验证新用户从安装 `rikkaST` 到成功导入复杂酒馆角色卡并完成首轮交互的全链路体验。

## 测试前置条件
- 全新安装或清除应用数据后的 `me.rerere.rikkahub.st` 客户端。
- 准备一个可用 API Key（如 DeepSeek / OpenRouter / Gemini）与测试角色卡 `36cf5ad94fc2908e.png`（或任意 `.charx` 角色卡）。

## 验证步骤与预期结果
1. **首启就绪横幅与向导**：
   - 打开应用进入聊天页，底部上方显示「尚未配置默认聊天模型，完成 2 步配置即可开聊」提示条。
   - 点击「极速配置」进入 `ModelWizardPage`，选择接口模板、填入 API Key，点击「测试连接」显示 `✅ 连接成功`，点击「保存并启用模型」自动返回并设为当前默认模型，提示条自动消失。
2. **一键导卡并开聊**：
   - 进入「助手」页或「新手向导」页，点击「一键导入角色卡 (.png / .json / .charx / .byaf)」，选择 `36cf5ad94fc2908e.png`。
   - 导入成功后自动绑定内嵌世界书、提取角色头像别名（`charx_assets/<id>/<id>.png`）、开启角色头像显示，并直接跳转到新会话。
3. **开场白渲染与状态栏头像核验**：
   - 首楼开场白中的状态栏、小手机面板与 `<div class="post-card">` 全部以 HTML 面板渲染，无裸露 CSS 或 `plaintext` 代码块。
   - 状态栏内的角色头像正常显示；面板右下角提供「重载面板」按钮，点击后可随时刷新面板。
4. **预设消息跳转与小手机浮窗交互**：
   - 点击预设消息面板中的分支跳转按钮，当前楼层立即切换到目标 `swipe_id` 并持久化。
   - 点击右侧「📱 小手机 / 悬浮窗」胶囊，弹出悬浮窗；切换标签页、点击换头像（触发系统文件选择器）、修改昵称（弹出原生确认框）、点击「不再显示」或「✕ 收起」均可正常关闭。
5. **发送消息与立即取消生成**：
   - 发送一条消息触发流式生成；在生成途中无论输入框为空还是已输入草稿文字，右下角均显示红色停止按钮。
   - 点击停止按钮后，2.5 秒内流式请求立即中断，按钮恢复可发送状态。
