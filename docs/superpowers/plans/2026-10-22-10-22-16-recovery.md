## Global Constraints

- `applicationId = "me.rerere.rikkahub.st"`
- `versionName = "2.5.9"`, `versionCode = 241`, Room DB version `32`
- No destructive Room migration (`fallbackToDestructiveMigration` forbidden) and no silent replacement of user providers/settings with `Settings.dummy()` or defaults on single-record corruption
- Sanitized diagnostic logging only — never log API keys, tokens, or secrets
- Truthful validation reporting: mark Gradle/Android SDK/APK certificate/device checks `BLOCKED` where the sandbox VM lacks Android SDK/network/device access

## Review Focus

1. Single malformed provider or model override in DataStore `providers` JSON array must not drop valid providers or leave `SettingsStore.settingsFlow` stuck at `Settings(init = true)`.
2. `PreferenceStoreV5Migration` must be wired into `createSettingsDataStore(migrations = ...)` and preserve legacy `balanceOption` → `quotaQuery` plus custom `baseUrl` and `customModels`.
3. ST-iPhonie floating modal must not re-trigger `openRealStIphoniePanel()` on Compose recomposition or allow `panelResized()` at 180ms/500ms to close and reopen `#sttts-panel`, which destroys open secondary sheets (`ctx.sheet`/`ctx.dialog`).
4. `GenerationLoop` pre-generation hooks (`runGenerationHooks`) must rethrow `CancellationException` rather than swallowing it in `runCatching`, and `ChatService.stopGeneration` must clear active generation state immediately (<200ms) while aborting active transport/hooks (<1s).
5. `MessageHtmlBlock` must bound active WebViews when `enableWebViewPerfReduction` is enabled (across both `HIBERNATE_POOL` and `LIVE_QUIESCENT`) and only capture full-bitmap WebView snapshots when `HISTORICAL_SNAPSHOT_IMAGE` mode is selected.
