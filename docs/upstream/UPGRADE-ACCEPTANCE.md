# 真机升级与回滚验收手册（v2.5.6 → v3.1.0 底座）

## 1. 覆盖升级验收步骤
1. 在已安装 `v2.5.6-public` 的设备上确认至少存在 1 张导入的角色卡、2 个历史会话、自定义正则与世界书条目。
2. 直接覆盖安装新版 APK（严禁卸载重装）。
3. 启动后验证：
   - 会话列表、消息分支树、`st_parent_conversation_id` 检查点、知识库（`knowledge_sources`）、记忆（`MemoryEntity` & `memory_file`）0 丢失；
   - 预设消息状态栏与 `post-card` HTML 片段正常渲染，气泡下方显示「重载面板」按钮；
   - 小手机悬浮窗支持二级页面关闭、「本次对话不再显示」与头像上传；
   - 生成期间无论输入框是否有草稿文字，右下角停止按钮均可见且点击后 2.5 秒内必定收敛。
